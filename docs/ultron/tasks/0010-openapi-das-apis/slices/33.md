## What to build

O host da API gera o documento OpenAPI pelo pacote nativo do .NET 10 e o publica em `/openapi/v1.json`, sempre disponível e anônimo. Cada deploy expõe só as rotas do módulo que liga: o documento de Lançamentos lista as rotas de Lançamentos, o de Consolidado as de Consolidado. O teste de integração sobe o host pelo `WebApiFactory` e lê o JSON do documento.

## Acceptance criteria

- [ ] `/openapi/v1.json` responde 200 no deploy de Lançamentos e lista só as rotas de Lançamentos
- [ ] `/openapi/v1.json` responde 200 no deploy de Consolidado e lista só as rotas de Consolidado
- [ ] O documento é acessível sem autenticação
- [ ] Suíte verde

## Blocked by

None — can start immediately.
